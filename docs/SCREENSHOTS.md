# Screenshot Checklist

Capture on an authorized Linux test VM:

1. `python3 toolkit.py`
2. System Information
3. SUID/SGID Discovery
4. Weak Permissions
5. Services
6. Sudo
7. Cron
8. Kernel/CVE review
9. Risk Analysis and final summary
10. Generated Markdown report
11. Generated JSON report

Do not include passwords, private keys, tokens or other sensitive data.
